# Сайт Lessa

Сайт приложения Lessa — кабинета репетитора в Telegram. Статические страницы без
сборки: открываются как есть, файлы скриптов и шрифтов лежат здесь же (без CDN и
Google Fonts — из России они грузятся с перебоями, а запросы к чужим серверам
передают им IP посетителей).

| Путь | Что это |
|---|---|
| `index.html` | главная: «день репетитора» с анимацией прокрутки |
| `offer/` | тарифы, оплата, возврат, публичная оферта, контакты и реквизиты — эту страницу проверяет платёжный сервис |
| `404.html` | страница «не найдено» |
| `doc.css` | стиль страниц-документов |
| `vendor/` | GSAP 3.12.5 + ScrollTrigger (стандартная лицензия GSAP), Lenis 1.1.13 (MIT), qrcodejs 1.0.0 (MIT) |
| `fonts/` | Geologica, Golos Text, Onest, Unbounded, Martian Mono — SIL Open Font License (тексты лицензий рядом) |

## Реквизиты

Реквизиты продавца стоят в разметке маркерами `{{SELLER_NAME}}`, `{{SELLER_INN}}`,
`{{SELLER_EMAIL}}` (главная — подвал, `offer/` — оферта, возврат, контакты).
**Публиковать сайт можно только после замены всех маркеров** — проверка:

```bash
grep -rn "{{SELLER_" --include=*.html .
```

## Цена

Цена указана в двух местах: `index.html` (блок «22:00», `s22__price`) и
`offer/index.html` (раздел «Стоимость»). Когда цена в админке Lessa меняется,
меняется и здесь.

## Публикация: GitHub Pages + свой домен

1. Репозиторий → Settings → Pages → Source: «Deploy from a branch», ветка `main`,
   папка `/ (root)`.
2. Там же Custom domain: `<домен>` → Save; после проверки DNS — «Enforce HTTPS».
   GitHub создаст файл `CNAME` с доменом.
3. DNS у регистратора (Timeweb → Домены → DNS):
   * четыре записи `A` для самого домена (`@`): `185.199.108.153`,
     `185.199.109.153`, `185.199.110.153`, `185.199.111.153`;
   * `CNAME` для `www` → `<имя-аккаунта>.github.io`.

Пока бесплатные GitHub Pages работают только у открытых репозиториев.
